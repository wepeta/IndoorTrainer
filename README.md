# IndoorTrainer — Web Bluetooth Trainer Controller

Control your smart trainer directly from the browser.
No app, no installation — just open the link.

🔗 **[Open Surge](https://username.github.io/surge/)**

## Features
- ERG mode (power control via FTMS)
- HR-based training mode
- Workout editor + .zwo import
- Live charts (power, cadence, HR)
- Post-workout summary with time in zones

## Requirements
- Chrome or Edge (desktop or Android)
- FTMS-compatible smart trainer
- Bluetooth heart rate monitor (optional)

## Supported Trainers
Wahoo KICKR, Tacx NEO 2T, Elite Direto,
Saris H3, Zwift Hub and all FTMS trainers.
